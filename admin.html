Conectar com o GitHub

Para salvar as alterações direto no site, crie um token de acesso pessoal (fine-grained) só para este repositório:

  1. Abra github.com/settings/personal-access-tokens/new
  2. Em Repository access, escolha Only select repositories → cantinho-da-leitura
  3. Em Permissions → Repository permissions, defina Contents como Read and write
  4. Clique em Generate token e copie (começa com github_pat_)

O token fica salvo só no seu navegador (localStorage) e é usado apenas para salvar no seu repositório. Não use esta página em computadores públicos. Você pode revogar o token quando quiser nas configurações do GitHub.
